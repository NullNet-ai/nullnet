# Quick setup

Steps to get a Nullnet cluster up and running quickly.
For more details, see SETUP.md.

- clone this repo into /root
- create ./members/nullnet-server/.env following SETUP.md
- run ./setup-server.sh on the manager node
- copy ./members/nullnet-server/grpc-tls/ca-cert.pem generated by the server to each node repo root
- create ./members/nullnet-proxy/.env following SETUP.md
- run ./setup-proxy.sh on the manager node
- create ./members/nullnet-client/.env following SETUP.md
- run ./setup-client.sh on each node (manager and workers)
- after the initial deployment, use ./prepare.sh, ./deploy.sh, and ./rollback.sh for upgrades
